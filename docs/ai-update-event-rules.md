# AI Update Event Rules

AI and scanner-generated events must be written in English.

Each event should:

- Identify the related industry.
- Identify the related company or supply chain node when possible.
- Use a standardized `impactType`.
- Include a concise English summary.
- Link to the best available source.
- Prefer English official evidence.
- Enter the review queue before changing official data.

## Standard Impact Types

- `supply_chain_importance`
- `bottleneck_judgement`
- `financial_update`
- `new_player`
- `relationship_change`
- `capacity_change`
- `technology_change`
- `policy_change`
