# Supply Chain Bottleneck Radar

This is a static web prototype for mapping industry supply chains and tracking important suppliers, chokepoint nodes, and underappreciated hidden bottleneck candidates.

The first fully populated industry is the automotive fuel cell industry.

## Core Features

- Render an industry supply chain map.
- Click a company node to inspect supplier importance, bottleneck position, hidden bottleneck score, and evidence sources.
- Let users submit official data, filings, announcements, or research notes.
- Route AI scan results and user submissions into a review desk.
- Support review states: approved, rejected, and needs more evidence.
- Export review decisions as JSON.
- Use GitHub Actions to semi-automatically apply reviewed data.

## Language And Source Policy

- English is the primary product language.
- Data fields, UI labels, review events, and generated scanner output should be written in English.
- Source collection prioritizes English official sources, investor relations pages, filings, government sources, standards bodies, and company materials.
- Non-English sources may be used only when they provide primary evidence that is not available in English; they should be summarized in English before entering the review workflow.

## Data Flow

```text
source-watchlist.json
  -> web-scan.mjs
  -> generated-update-events.json
  -> review desk
  -> exported review-decisions JSON
  -> apply-review-decisions.mjs
  -> industries.reviewed.json
  -> promote-reviewed-data.mjs
  -> industries.json
```

## Important Files

- `index.html`: Web entry point.
- `app.js`: Supply chain map and review desk logic.
- `review-export.js`: Review decision export.
- `data/industries.json`: Official industry map data.
- `data/source-watchlist.json`: Daily and weekly source watchlist.
- `data/generated-update-events.json`: Candidate events generated by AI or scanners.
- `scripts/web-scan.mjs`: Real web page scanner prototype.
- `scripts/apply-review-decisions.mjs`: Applies approved review decisions to reviewed data.
- `scripts/promote-reviewed-data.mjs`: Promotes reviewed data after human confirmation.

## GitHub Actions

- `Source Scan`: Scans source pages and generates candidate events.
- `Deploy Static Site`: Publishes the static app to GitHub Pages on every push to `main`.
- `Apply Review Decisions`: Reads exported review JSON and generates `industries.reviewed.json`.
- `Promote Reviewed Data`: Promotes reviewed data to official `industries.json` after manual confirmation.

## Risk Controls

- Scanners generate review candidates only; they do not directly edit the official map.
- Review application generates a reviewed candidate file; it does not directly overwrite official data.
- Promotion must be manually triggered and requires the confirmation word `PROMOTE`.
- Company scores, hidden bottleneck labels, nodes, and edges are not automatically changed without review.
