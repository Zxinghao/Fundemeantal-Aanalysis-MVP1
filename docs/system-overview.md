# System Overview

## Product Goal

The platform maps an industry from end demand to systems, components, materials, and companies. The goal is to identify critical supply chain bottlenecks and underappreciated hidden bottleneck candidates.

The first complete industry is automotive fuel cells.

## Frontend Modules

### Supply Chain Map

Files:

- `index.html`
- `app.js`
- `styles.css`
- `apple-style.css`

Functions:

- Render the industry map.
- Draw supply chain nodes and relationship edges.
- Open a company detail dialog when a company node is clicked.
- Display evidence sources and hidden bottleneck scores.

### Review Desk

Files:

- `app.js`
- `review-export.js`
- `review-export.css`

Functions:

- Merge AI scan events, map candidates, and user submissions.
- Support review states: pending, approved, rejected, and needs more evidence.
- Store review decisions in browser local storage.
- Export reviewed decisions as JSON.

## Data Modules

### Official Data

File:

- `data/industries.json`

Includes:

- Industry descriptions.
- Supply chain nodes.
- Relationships.
- Company profiles.
- Scores and signals.
- Official update events.
- `languagePolicy`, which declares English as the primary language and prioritizes English official sources.

### Watchlist

File:

- `data/source-watchlist.json`

Includes:

- Daily and weekly monitored sources.
- Company IDs.
- Node IDs.
- Keywords.
- Source language metadata.

### Scan Results

File:

- `data/generated-update-events.json`

This file stores candidate events generated by the scanners. The frontend loads it first, then falls back to the sample file when needed.

## Automation Modules

### Source Scan

File:

- `scripts/web-scan.mjs`

Purpose:

- Scan English-priority source pages.
- Detect page-content fingerprint changes.
- Write `source-cache.json` and `generated-update-events.json`.

### Apply Review Decisions

File:

- `scripts/apply-review-decisions.mjs`

Purpose:

- Read exported review JSON.
- Apply only approved items.
- Generate `data/industries.reviewed.json`.

### Promote Reviewed Data

File:

- `scripts/promote-reviewed-data.mjs`

Purpose:

- Promote `industries.reviewed.json` to `industries.json` after manual confirmation.
- Preserve the previous official data version.

## Usage Flow

1. Open the hosted preview.
2. Review the supply chain map and company dialogs.
3. Process AI scan events in the review desk.
4. Export review decisions.
5. Add the exported JSON to the repository.
6. Run `Apply Review Decisions`.
7. Inspect `industries.reviewed.json`.
8. Run `Promote Reviewed Data` after confirmation.
9. The live page reads the updated `industries.json`.

## Current Limits

- The app is still a static web page without database or login.
- Review decisions are stored locally and must be exported manually.
- The scanner detects page changes but does not interpret investment meaning automatically.
- Review application does not automatically change scores, nodes, or edges.
